# Repo Continuity v4.5.1

Documentation updates now have an explicit responsibility check before writing. Task-specific state stays in its WORK and individual route, while shared entry points and policies change when their own navigation or repository-wide contract changes.

## What Changed

- Added canonical writing boundaries for rules, navigation, workflow, Git policy, task records, routes and domain knowledge.
- Aligned the payload and Companion Skill with the writing check and verified reusable-value requirement.
- Reduced repeated route guidance in the WORK template.
- Added a distribution regression for task creation's file scope and guidance for reviewing actual Agent diffs.

## Upgrade

Install the Skill pinned to v4.5.1 and reconcile existing projects through the three-way upgrade workflow. Projects upgrading from v4.4.x also need the open-work routing migration introduced in v4.5.0. Preserve project-owned rules and validated local customization during reconciliation.

See [PR #9](https://github.com/vector233/repo-continuity/pull/9), the [upgrade guide](../upgrading.md) and the [knowledge lifecycle](../../template/zettelkasten/knowledge-lifecycle.md).
